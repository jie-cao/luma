## 1. 功能概述

LUMA Studio 角色创建系统提供从零开始或基于照片生成 3D 角色的完整工作流，包括：

| 功能模块 | 说明 |
|---------|------|
| **5 种创建方式** | 模板创建、照片 AI 生成、预设选择、随机生成、空白角色 |
| **5 种角色风格** | 写实 (Realistic)、风格化 (Stylized)、动漫 (Anime)、卡通 (Cartoon)、Q版 (Chibi) |
| **70+ 面部参数** | 分布在 10 个面部区域，支持实时拖拽调整 |
| **52 个表情控制** | ARKit 标准混合变形，30+ 预设表情 |
| **19 项体型参数** | 身高/体重/肌肉/各部位比例，13 种体型预设 |
| **发型与服装** | 5 类发型 + 12 种发色，10 类服装部位 |
| **照片 AI 生成 (MetaHuman 风格)** | 支持 1-3 张照片（正面+侧面），ONNX 模型推理 + 几何回退，多视角融合 |
| **PBR 渲染** | 皮肤 SSS、眼球折射、头发各向异性高光 |
| **撤销/重做** | 面部编辑支持最多 50 步撤销 (Ctrl+Z / Ctrl+Y) |
| **5 种导出格式** | glTF 2.0、FBX、OBJ、VRM、USD |
| **中英文 UI** | 全部界面元素支持中/英文切换 |

## 2. 进入角色模式

### 功能说明

角色模式 (Character Mode) 是编辑器的独立工作模式，与场景模式、编辑模式并列。

### 操作步骤

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 2.1 | 启动 LUMA Studio | 进入欢迎/场景界面，顶部模式栏可见 |
| 2.2a | 点击顶部模式栏的 **"角色"** 按钮 | 切换到角色模式，右侧出现角色检查器面板 |
| 2.2b | 或在空白场景中点击 **"创建角色"** 按钮 | 自动切换到角色模式并创建默认人形角色 |
| 2.2c | 或右键菜单 → 添加物体 → **"创建角色"** | 自动切换到角色模式并创建默认人形角色 |
| 2.3 | 点击面板底部 **"返回场景"** 按钮 | 退出角色模式，角色保留在场景中 |

### 界面布局

```
┌─────────────────────────────────────────────────────┐
│  [场景] [角色] [编辑] [动画] [播放]    ← 模式栏     │
├───────────────────────────────┬─────────────────────┤
│                               │  角色模式 - 检查器    │
│                               │  [总览][体型][面部]   │
│       3D 视口                  │  [发型][服装][表情]   │
│     (角色实时预览)              │  [导出]              │
│                               │                     │
│                               │  (当前子模式面板)     │
│                               │                     │
│                               │  [返回场景]          │
└───────────────────────────────┴─────────────────────┘
```

## 3. 角色创建工作流

### 3.1 从模板创建

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 3.1.1 | 进入角色模式 → 总览面板 | 显示创建选项 |
| 3.1.2 | 在"风格"中选择一种（如"写实"） | 对应按钮高亮 |
| 3.1.3 | 点击 **"从模板创建"** | 创建默认人形角色，3D 视口中显示模型 |

可用模板：

| 模板 | 说明 | 默认身高 | 特色 |
|------|------|---------|------|
| Human | 标准人形 | 1.8m | 完整骨骼、手指脚趾、混合变形 |
| Mascot | 吉祥物（三丽鸥风格） | 1.0m | 猫耳、蝴蝶结、无嘴 |
| Cartoon | 卡通（迪士尼风格） | 1.2m | 大圆耳、手套手、大鞋 |

### 3.2 从照片 AI 生成（MetaHuman 风格多照片）

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 3.2.1 | 点击 **"从照片生成 (AI)"** | 弹出多照片导入对话框 |
| 3.2.2 | 在 **"Front Photo (Required)"** 槽位点击"..." | 弹出文件选择对话框 |
| 3.2.3 | 选择正面照片 (JPG/PNG/BMP) | 文件路径显示，状态变为 [OK] |
| 3.2.4 | （可选）在 **"Left Profile"** 槽位选择左侧面照 | 增加侧面信息用于深度参数 |
| 3.2.5 | （可选）在 **"Right Profile"** 槽位选择右侧面照 | 增加侧面信息用于深度参数 |
| 3.2.6 | 点击 **"Generate Face"** | 显示进度条和各照片处理状态 |
| 3.2.7 | 等待处理完成 | 3D 角色面部通过多视角融合匹配照片特征 |
| 3.2.8 | 在面部面板中微调参数 | 可在 AI 生成基础上继续手动调整 |

**多照片策略**：
- **仅正面照**：所有参数均从正面估计，宽度类参数（脸宽、眼距、鼻宽）精度较高，深度类参数（鼻高、下巴突出度）依赖 3DDFA 的单图估计
- **正面 + 侧面照**：宽度参数取正面结果（权重 0.8），深度参数取侧面结果（权重 0.8），显著提升 3D 还原精度
- **三张照片**：最佳效果，左右侧面信息互相验证

### 3.3 随机生成

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 3.3.1 | 点击 **"随机生成"** | 以随机种子生成角色，面部/体型参数随机 |
| 3.3.2 | 不满意可再次点击 | 每次生成不同结果 |

### 3.4 从预设创建

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 3.4.1 | 在总览面板滚动到"面部预设"列表 | 显示可用预设按钮 |
| 3.4.2 | 点击任一预设（如"平均男性"） | 创建角色并应用该预设的面部参数 |

默认面部预设：

| 预设名称 | 说明 |
|---------|------|
| Average Male | 标准男性面部 |
| Strong Male | 硬朗男性（宽下颌、低眉、高颧骨） |
| Average Female | 标准女性面部 |
| Soft Female | 柔和女性（圆脸、大眼、饱满脸颊） |
| Elf | 精灵（长脸、大眼、尖耳） |

### 3.5 空白角色

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 3.5.1 | 点击 **"空白角色"** | 创建所有参数为默认值 (0.5) 的角色 |

## 5. 体型编辑 (Body)

### 功能说明

调整角色的整体体型、各部位比例和肤色。支持性别切换和体型预设。

### UI 元素与参数

#### 性别选择

| 控件 | 选项 | 说明 |
|------|------|------|
| 单选按钮 | 男性 / 女性 | 切换后自动更新混合变形权重 |

#### 身材比例 (折叠面板，默认展开)

| 参数 | 滑条范围 | 说明 |
|------|---------|------|
| 身高 (Height) | 0.0 — 1.0 | 0 = 矮, 1 = 高 |
| 体重 (Weight) | 0.0 — 1.0 | 0 = 瘦, 1 = 重 |
| 肌肉 (Muscularity) | 0.0 — 1.0 | 0 = 柔和, 1 = 肌肉发达 |

#### 上半身 (折叠面板)

| 参数 | 滑条范围 | 说明 |
|------|---------|------|
| 肩宽 (Shoulder Width) | 0.0 — 1.0 | 肩部宽度 |
| 胸围 (Chest) | 0.0 — 1.0 | 胸部尺寸 |
| 腰围 (Waist) | 0.0 — 1.0 | 腰部围度 |
| 臂长 (Arm Length) | 0.0 — 1.0 | 手臂相对长度 |

#### 下半身 (折叠面板)

| 参数 | 滑条范围 | 说明 |
|------|---------|------|
| 臀宽 (Hip Width) | 0.0 — 1.0 | 臀部宽度 |
| 腿长 (Leg Length) | 0.0 — 1.0 | 腿部相对长度 |

#### 肤色 (折叠面板，默认展开)

| 控件 | 说明 |
|------|------|
| 颜色选择器 (ColorEdit3) | RGB 拾色器，调整皮肤基础色 |

#### 体型预设

| 预设 | 对应枚举值 | 说明 |
|------|----------|------|
| 运动型 (Athletic) | MaleMuscular | 宽肩窄腰 |

| 普通 (Average) | MaleAverage | 标准体型 |
| 壮实 (Heavy) | MaleHeavy | 偏壮体型 |
| 肌肉型 (Muscular) | MaleMuscular | 高度肌肉化 |

### 操作步骤

| 步骤 | 操作 | 预期结果 |

## 6. 面部雕塑 (Face)

### 功能说明

最核心的功能模块。提供 70+ 个面部形状参数，分布在 10 个区域，支持实时调整、撤销/重做、面部预设。编辑时 3D 视口中会高亮显示当前编辑区域。

### 面部区域

| 区域 | 英文 | 参数数量 | 主要参数 |
|------|------|---------|---------|
| 整体 | Overall | 3 | 脸宽、脸长、圆润度 |
| 额头 | Forehead | 3 | 高度、宽度、倾斜度 |
| 眼睛 | Eyes | 10 | 大小、宽度、高度、间距、角度、深度、上/下眼皮、内/外眼角 |
| 眉毛 | Brows | 6 | 高度、粗细、长度、角度、间距、弧度 |
| 鼻子 | Nose | 9 | 长度、宽度、高度、鼻梁、鼻梁弧度、鼻尖、鼻尖角度、鼻翼宽度、鼻翼外张 |
| 嘴巴 | Mouth | 8 | 宽度、高度、上/下唇厚度、嘴唇突出、嘴角、人中、唇弧度 |
| 下巴 | Chin | 5 | 长度、宽度、突出度、形状、下巴裂 |
| 下颌 | Jaw | 3 | 宽度、角度、下颌线 |
| 脸颊 | Cheeks | 5 | 颧骨高度、颧骨宽度、颧骨突出、脸颊丰满度、脸颊脂肪 |
| 耳朵 | Ears | 4 | 大小、角度、耳垂、尖度 |

### 外观参数

| 参数 | 控件类型 | 说明 |
|------|---------|------|
| 肤色 (Skin Tone) | 颜色选择器 | 面部皮肤基础色 |
| 眼睛颜色 (Eye Color) | 颜色选择器 | 虹膜颜色 |
| 嘴唇颜色 (Lip Color) | 颜色选择器 | 唇色 |
| 皱纹 (Wrinkles) | 滑条 0-1 | 皱纹深度 |
| 雀斑 (Freckles) | 滑条 0-1 | 雀斑密度 |
| 皮肤粗糙度 (Skin Roughness) | 滑条 0-1 | PBR 粗糙度 |

### 操作步骤

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 6.1 | 点击"面部"标签 | 切换到面部编辑面板 |
| 6.2 | 点击"眼睛"区域标签 | 显示眼部相关滑条，3D 视口高亮眼部区域 |
| 6.3 | 拖动"眼睛大小"滑条 | 角色眼睛实时变大/变小 |
| 6.4 | 点击参数旁的 **"R"** 按钮 | 该参数重置为默认值 (0.5) |
| 6.5 | 按 **Ctrl+Z** | 撤销上一步调整 |
| 6.6 | 按 **Ctrl+Y** | 重做已撤销的调整 |
| 6.7 | 点击 **"重置全部"** | 所有面部参数回到默认值 |
| 6.8 | 在面部预设列表中选择一个预设 | 面部参数一次性应用 |
| 6.9 | 切换到"鼻子"区域 | 高亮切换到鼻部，显示鼻部参数 |
| 6.10 | 修改外观参数（如眼睛颜色） | 渲染实时更新 |

### 面部约束系统

系统内置参数约束，确保面部比例合理：
- 相关参数自动联动（如下颌宽度影响下巴宽度）
- 极端值会被适度校正以保持可信面部形态
- 支持对称编辑（表情镜像）

- [ ] 所有 70+ 个滑条可拖动，范围正确

## 11. 照片生成角色 (AI) — MetaHuman 风格

### 功能说明

通过导入 1-3 张人脸照片（正面 + 可选侧面），AI 管线自动进行人脸检测、特征点定位、3DMM 系数回归，经多视角融合后映射到 56 个面部形状参数，同时提取皮肤纹理和肤色。参考 MetaHuman 的多照片输入和固定拓扑模板网格方式设计。

### 技术管线

```
┌─────────────────────────────────────────────────────────────────────┐
│  多照片输入（MetaHuman 风格 3 槽位）                                    │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐                            │
│  │ 正面照片 │  │ 左侧照片 │  │ 右侧照片 │                            │
│  │ (必需)   │  │ (可选)   │  │ (可选)   │                            │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘                            │
│       │             │             │                                  │
│  ┌────▼─────────────▼─────────────▼────┐                            │
│  │  FaceDetector (InsightFace RetinaFace ONNX)                     │
│  │  → 人脸框 + 置信度 + 5点关键位                                    │
│  └────┬────────────────────────────────┘                            │
│       │                                                             │
│  ┌────▼────────────────────────────────┐                            │
│  │  FaceLandmarkDetector (InsightFace 2d106det ONNX)               │
│  │  → 68/106 个 2D 面部特征点                                       │
│  └────┬────────────────────────────────┘                            │
│       │                                                             │
│  ┌────▼────────────────────────────────┐                            │
│  │  Face3DMMRegressor (3DDFA_V2 ONNX)                              │
│  │  → 40 维 identity + 29 维 expression + 12 维 pose               │
│  │  + landmark 辅助几何比例回归                                      │
│  └────┬────────────────────────────────┘                            │
│       │                                                             │
│  ┌────▼────────────────────────────────┐                            │
│  │  MultiViewFusion 多视角融合                                       │

│  │  侧面 → 深度类参数 (权重 0.8)                                     │

│       │                                                             │

│  │  参数化曲面 + 中点细分 + 32 个混合形状                             │
│  │  应用 56 参数驱动变形                                             │
│  └─────────────────────────────────────┘                            │
└─────────────────────────────────────────────────────────────────────┘
```

### AI 模型依赖

| 模型 | 文件名 | 大小 | 来源 | 用途 |

### 多视角融合策略

| 参数类别 | 主要来源 | 权重分配 |
|---------|---------|---------|
| 宽度类（脸宽、眼距、鼻宽、嘴宽、下颌宽） | 正面照 | 正面 80% + 3DMM 20% |
| 深度类（鼻高、下巴突出、前额倾斜、嘴唇突出、眼窝深度） | 侧面照 | 侧面 80% + 正面3DMM 20% |
| 仅正面照时的深度参数 | 3DDFA 单图估计 | 3DMM 100% |

### 回退机制

系统采用三级回退策略，确保无论是否有 ONNX 模型均可正常使用：

| 级别 | 条件 | 行为 | 精度 |
|------|------|------|------|
| **L1: 完整 AI** | ONNX Runtime + 3 个模型文件均存在 | RetinaFace 检测 → InsightFace landmarks → 3DDFA 回归 → 融合 | 最高 |
| **L2: Landmark 几何** | ONNX 可用但部分模型缺失 | 皮肤色检测 + 几何比例回归（眼距/脸宽/鼻宽等比例映射） | 中等 |
| **L3: 几何启发式** | 无 ONNX Runtime | 皮肤颜色直方图定位 → 68 点估计 → 比例回归 → 肤色采样 | 基础 |

所有级别均提供：
- 真实的肤色从照片像素采样（颊骨区域多点采样取均值）
- 照片尺寸信息用于确定比例
- 纹理提取（基于 landmark 的 UV 投影，512×512）
- 亮度归一化处理

### 面部模板网格技术

生成的面部使用 `FaceTemplateMesh` 高质量模板替代旧的圆柱截面方法：

| 特性 | 旧方案（圆柱截面） | 新方案（参数化模板） |
|------|-------------------|-------------------|
| 头部几何 | 椭圆截面拉伸 | 解剖学参数化曲面 + 细分 |
| 顶点数 | ~700（头部区域） | ~2500+（细分后） |
| 面部特征 | 简单偏移函数 | 鼻/眼窝/唇/颧骨/耳独立建模 |
| 混合形状 | 28 个（在圆柱上定义） | 32 个（解剖学驱动，独立定义） |
| 法线质量 | 近似径向 | 三角面法线加权平均 |
| 前脸形状 | 圆柱曲面（不自然） | 前脸扁平化 + 特征突出 |

## 附录 D: ONNX Runtime 与 AI 模型配置

### 编译配置

ONNX Runtime 通过 CMake `FetchContent` 自动下载（仅 Windows x64），由 `LUMA_USE_ONNXRUNTIME` 选项控制：

```cmake
option(LUMA_USE_ONNXRUNTIME "Enable ONNX Runtime for AI-powered face analysis" ON)
```

编译成功后，`onnxruntime.dll` 会自动复制到可执行文件目录。

### ONNX 模型下载

| 模型 | 下载地址 | 放置路径 |
|------|---------|---------|
| RetinaFace 检测 | [InsightFace Model Zoo](https://github.com/deepinsight/insightface/tree/master/model_zoo) | `models/det_10g.onnx` |
| 2D106 特征点 | [InsightFace Model Zoo](https://github.com/deepinsight/insightface/tree/master/model_zoo) | `models/2d106det.onnx` |
| 3DDFA MobileNet | [3DDFA_V2 Releases](https://github.com/cleardusk/3DDFA_V2) | `models/mb1_120x120.onnx` |

### 验证方式

1. 编译后检查 `build/` 目录下是否有 `onnxruntime.dll`
2. 启动程序，控制台应输出 `ONNX Runtime x.xx.x enabled`
3. 从照片生成时，如模型加载失败会输出 `[WARN] Model not found, using fallback`
