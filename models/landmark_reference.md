## 68 点分布

```
点位范围        区域              说明
─────────────────────────────────────────────
0  - 16        Jawline           下颌轮廓（右耳→下巴→左耳）
17 - 21        Right Eyebrow     右眉毛（图像左侧，人脸右侧）
22 - 26        Left Eyebrow      左眉毛（图像右侧，人脸左侧）
27 - 30        Nose Bridge       鼻梁
31 - 35        Nose Bottom       鼻子底部（鼻翼、鼻孔、鼻尖）
36 - 41        Right Eye         右眼（图像左侧）
42 - 47        Left Eye          左眼（图像右侧）
48 - 59        Outer Lip         外嘴唇轮廓
60 - 67        Inner Lip         内嘴唇轮廓
```

## 详细点位说明

### 下颌轮廓 (0-16)
```
0:  右耳下方（图像最左）
1-7: 右侧下颌线
8:  下巴最低点（正中）
9-15: 左侧下颌线  
16: 左耳下方（图像最右）
```

### 眉毛 (17-26)
```
右眉毛 (17-21):
  17: 内侧起点（靠近鼻梁）
  18-20: 中间点
  21: 外侧终点

左眉毛 (22-26):
  22: 内侧起点（靠近鼻梁）
  23-25: 中间点
  26: 外侧终点
```

### 鼻子 (27-35)
```
鼻梁 (27-30):
  27: 眉心位置（最高点）
  28-29: 鼻梁中部
  30: 鼻梁底部

鼻底 (31-35):
  31: 右鼻翼外侧
  32: 右鼻孔
  33: 鼻尖
  34: 左鼻孔
  35: 左鼻翼外侧
```

### 眼睛 (36-47)
```
右眼 (36-41) - 顺时针:
  36: 外眼角
  37: 上眼睑外侧
  38: 上眼睑内侧
  39: 内眼角
  40: 下眼睑内侧
  41: 下眼睑外侧

左眼 (42-47) - 顺时针:
  42: 内眼角
  43: 上眼睑内侧
  44: 上眼睑外侧
  45: 外眼角
  46: 下眼睑外侧
  47: 下眼睑内侧
```

### 嘴唇 (48-67)
```
外嘴唇 (48-59) - 顺时针:
  48: 右嘴角
  49-53: 上唇（右→左）
  54: 左嘴角
  55-59: 下唇（左→右）

内嘴唇 (60-67) - 顺时针:
  60: 右内角
  61-63: 内上唇
  64: 左内角
  65-67: 内下唇
```

## 注意事项

1. **左右约定**: iBUG 使用的是**图像坐标**，即：
   - "Right" = 图像左侧 = 人脸的右侧
   - "Left" = 图像右侧 = 人脸的左侧

2. **索引起始**: 点位从 0 开始编号（0-67）

3. **顺序规律**:
   - 下颌线：从右到左
   - 眉毛：从内到外
   - 眼睛：顺时针方向
   - 嘴唇：顺时针方向

## 在 LUMA Studio 中使用

1. 打开 Character 模式
2. 在 Overview 页面展开 "开发工具: Landmark 标记"
3. 点击 "打开 Landmark 编辑器 (自动识别)"
4. 参考本文档微调各个点位
5. 完成后点击 "保存映射"
